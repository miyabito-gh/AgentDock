## 4. 所有者違いのリポジトリ（HANDOFF 21・29）— DocTrail で
前提: 作業フォルダに **DocTrail** を選んだチャット（既存のDocTrailのチャット、または新規作成時に作業フォルダを指定）で行う。一般チャット（作業フォルダがAgentDock管理の一般用フォルダ）はgitリポジトリでないため、何も出ないのが正しい。
1. DocTrailのチャットを開いた直後（送信前）に、チャット名の右端「…」→「差分を確認」（またはCtrl+K）。
   期待: グレーアウトされない（以前は『Gitリポジトリではありません』で無効だった）。「Git上の現在の差分」タブに原因文言と「対処の案内を見る」ボタン。押すと「控え基準」タブで「このリポジトリの変更を記録しますか」［記録する／記録しない］。
2. 発言を送る。期待: 警告のトーストは出ない。送信は止まらない。
3. 「記録する」を押す。期待: ①先に自分で git init、②.git の所有者を戻すコマンド（コピー可）、③safe.directory のコマンド（コピー可）、④「AgentDockのgit操作だけに許可」の案内。AgentDockは勝手に実行しない。
4. ④を試す: ボタン → 確認ダイアログでパスを確認 → 許可。期待: 「Git上の現在の差分」タブに差分が出る。以降の送信で控えが取れて「変更を戻す」が使える。設定画面の「保存と容量」の「リポジトリ別の記録」から許可を解除できる。
   許可済みでも worktree作成・クラウド取込みは失敗する（許可は差分の確認と変更の記録だけに効く）。その場合の文言が「AgentDockだけの許可は…効きます。…safe.directory 登録、または .git の所有者を戻す…」になること。
5. 「記録しない」を選ぶ場合: 以降の送信でgitを呼ばず、メッセージも出ない。変更ダイアログに中立の一行（記録しない設定）と「このリポジトリの記録を有効にする」だけが出る。
6. 再起動して、選択が残っていること。
7. 所有者が同じ通常のリポジトリ（AgentDockなど）では、何も聞かれないこと。
注意: すでに送ったturnは、後から対処しても戻せるようにならない。
