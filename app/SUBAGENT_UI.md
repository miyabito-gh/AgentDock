# サブエージェント UI 引き継ぎ

## 実装した内容

- `サブエージェントで依頼` をチャットメニューとコマンド検索に追加。
- 専用worktreeでの依頼開始、実行履歴の読込、親チャットを開く操作、明示的な親チャット復旧を追加。
- 観測した子エージェントの状態と情報の鮮度、開始段階、障害・阻害理由を表示。
- worktreeが元リポジトリの未コミット変更を含まないこと、同時編集数1は依頼文による指示であることを表示。
- 取り込み前にHEADとファイル一覧を表示し、ユーザー確認後に一回限りのトークンで実行するUIを追加。未確定・部分適用は自動再試行せず、明示的な台帳確認を提供。
- `src/ipc/subagents.ts` に型付きIPC呼出しを追加。

## 残課題

- `npm.cmd run type-check` と `npm.cmd run build` を一度実行して型・buildを確認する。
- 型エラーがあればこのUI/IPC範囲を修正する。
- 実機受入は専用ローカルテストリポジトリを使い、ユーザー承認を代行せずに確認する。
- `App.tsx` と `Dialogs.tsx` は通常改善のステージ済み差分にUI変更を重ねている。通常改善コミット前に、それらの未ステージ差分がサブエージェントUIだけであることを確認する。

作業停止時点で、UIの検証コマンドは走っていない。コミット・push・実機起動は行っていない。
