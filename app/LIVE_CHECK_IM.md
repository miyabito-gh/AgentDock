# 実機確認: 改善1〜5（2026-10-15）

実機確認はユーザーが行う。設計は DESIGN_IMPROVE.md、レビューは REVIEW_IM.md。

## 1・2 クイック新規と作成中の表示
1. 左上に「新しいチャット」と小さなクイック新規ボタンの2つがある。
2. クイック新規（または Ctrl+N）で、すぐ中央に入力欄が出る。何も送らなければ会話は作られない（一覧に増えない）。
3. 文を入れて送信すると、一覧の先頭に「作成中…」の仮行が出て、作成後に実チャットが選ばれ、最初の依頼が「送信中」と表示される。
4. 詳細ダイアログ（Ctrl+Shift+N）で作成ボタンを押すと、押した直後にボタンが無効化され「作成中…」と出る。連打しても会話が2つできない。
5. 作成中に App Server を切るなどして失敗させる: 理由つきの行と「入力し直す…」が出る（自動で再送されない）。「作られたか分からない」ときは「一覧を更新」だけが案内され、本文をコピーできる。
6. 作成直後（最初の送信が確定する前）に、そのチャットを削除・アーカイブしても、確定前に消えない。

## 3・4 右ペインのタスクカード
1. 右ペインの既定表示が「タスク」。「タスク｜選択中｜全」で切り替わり、「実行中」は無い。
2. 複数チャットを動かすと、最近動かした順に最大5件のカードが並ぶ。6件目以降は「ほかのタスク」に出る。
3. 完了してもカードが消えず、次の指示欄から続けて指示を送れる。×で閉じたカードは新しい活動で戻る。
4. 実行中カードは子孫を直近3件と「ほかN件」で出し、高さはペインの約1/3で内部スクロールする。完了カードは子孫を出さない。
5. 承認・質問が来ると、先頭の固定帯にカードが出て、許可・拒否・回答はその1件にだけ効く。
6. カードの指示欄に文字を打っている最中は、並び替え・スクロール・展開が起きず、入力とIME変換が途切れない。
7. 右ペインを低く・狭くすると、カードが1行表示になる。
8. コンパクト監視窓には、回答ボタンと指示欄が出ない。

## 5 左ペイン折りたたみと幅
1. 左を折りたたんだ状態で窓幅を狭くすると、約740pxまで右ペインが並置のまま残る。
2. 左を開いた状態（既定幅）では、約980pxまで右ペインが並置、それ未満で一時パネル（前面）になる。
3. 約660px未満では左右とも一時パネルになる。折りたたみ中に一時パネルが勝手に開かない。
4. ペイン幅のドラッグ変更の保存値が、窓幅を変えても変わらない。
