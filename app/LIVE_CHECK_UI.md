# 実機確認手順 — 段階④-UI（見た目の改善）

見た目だけの変更なので、**動作が前と同じか**と**見た目が読みやすいか**を見る。消した・移した文言の一覧は DESIGN_UI.md §7。

## 0. 準備


インストーラーの指示に従って上書きインストールし、AgentDockを起動する。

## 1. 会話の見える量（今回の主目的）

1. 既存の会話（できれば再起動後の履歴のみのチャット）を開く。ウィンドウは最大化（1080pxの高さ）。
2. 見る: ヘッダーが**1行**（題名・状態・鮮度・作業フォルダ・「…」）で、入力欄が**2行＋操作1行**に収まり、会話が縦に広い。以前あった「保存履歴から表示しています」の黄色い帯が出ない。
3. 鮮度の「履歴のみ」をクリック → 吹き出しに旧帯と同じ説明が出る（Escで閉じる）。
4. アプリ内の疑似タイトルバー（最小化・最大化ボタンの行）が無く、Windows標準のタイトルバーだけ。右端付近のメニューバーに「Codex 0.160.0」が出る。クリックして接続先メニューが開く。×を押すとトレイに格納される。

## 2. ヘッダーの「…」メニュー

1. ヘッダー右端の「…」をクリック。差分・変更を戻す・レビュー・分岐・Goal・作業フォルダ変更・状態を再照合・すべての操作（Ctrl+K）が並ぶ。
2. 見る: 未確認の操作は名前の直後に灰色の枠で「未確認」。使えない操作は理由がツールチップに出る。
3. 差分を開く → 閉じる。変更を戻すを開き、フッターの右下に「戻す」系ボタン、左下に副操作、右端に「閉じる」。**実際に戻す操作はしなくてよい**（開いて内容を見るだけ）。
4. 実行中のチャットで、入力欄の「中断」が押せる（ヘッダーの中断は無くなった）。

## 3. 入力欄

1. 入力欄の右下付近の「⋯」をクリック → 速度・計画／実行・受理の全文が出る。
2. モデルや推論の選択を変えて送る前後で、1行目に「未受理」「受理未確認」が出るか（変更後すぐ）。受理後は消える。
3. 長文を貼ると入力欄が最大160pxまで伸び、送信後に元の高さへ戻る。日本語入力（IME変換中）で文字が飛ばない。

## 4. 左一覧とドック

1. 左一覧: 上部が2行（新規＋更新／検索）。行が詰まっている。検索に文字を入れると「アーカイブも含める」が出る。
2. ドック（親子エージェントがいるチャット）: 上部1行。「表示 ▾」から「親のみ」「終了済みも表示」を切替。「?」で説明。子カードに役割・担当・パス・活動・時刻が収まり、**横スクロールが出ない**。失敗した子の「確認済みに」で隠せる。
3. 状態の色: 実行中＝青、要対応＝黄、失敗＝赤、完了＝緑✓、状態不明＝破線。**黄色は承認・質問などの要対応だけ**に使われている。

## 5. ペイン幅の変更（新機能）

1. 左一覧とチャット本文の境目にマウスを置く → 左右矢印のカーソル。ドラッグで幅が変わる（180〜400px）。ドックの境目も同様（260〜520px）。
2. 境目をクリックしてフォーカスし、←→（8px）、Shift+←→（32px）、Home／End（最小／最大）、Enter（既定幅）。ダブルクリックでも既定幅に戻る。ドラッグ中にEscで元に戻る。
3. 幅を変えてアプリを**完全終了→再起動**（トレイの「終了」）。幅が復元される。
4. ウィンドウを狭める: 1279px以下でドックが一時パネルに、959px以下で左一覧も一時パネルになり、ハンドルは出ない。広げると保存した幅に戻る。

# 段階⑤の確認（追記。同じNSIS版で）

設計は `app/DESIGN_P5.md`、レビューは `app/REVIEW_R5.md`。

## 10. 左ペイン: 行の「…」と作業フォルダ表示

1. 左一覧の任意の行にマウスを乗せ、右端の「…」をクリック → 名前変更・ピン・アーカイブ・エクスポート・削除。選択中ではない行でも、**その行のチャット**に作用する（削除・アーカイブは確認ダイアログの名前を必ず見る）。
2. 行を右クリック、またはTabで行へ移動して Shift+F10 → 同じメニュー。Escで閉じる。メニューを開いただけでは選択も並びも変わらない。
3. 一覧上部「表示 ▾」→「作業フォルダごと」。作業フォルダごとの見出し（パスは末尾2階層）。見出しのクリックで折りたたみ（件数の印）、見出しの「…」でフォルダのピン止め・パスをコピー。ピン止めしたフォルダが上に並ぶ。AgentDockが作ったworktreeのチャットは元リポジトリの見出しに入る。
4. アプリを完全終了→再起動しても、表示切替・折りたたみ・フォルダのピンが残る。

## 11. Markdown表示

1. 見出し・箇条書き・表・コードブロック・太字・リンクを含む応答を出させる（例: 「見出しと表とコードを含むMarkdownで説明して」）。整形されて表示される。コードブロックの「コピー」でクリップボードに入る。
2. 応答の「コピー」ボタン（ホバー）で本文がコピーされる。
3. リンクをクリック → アプリ内で遷移せず、行き先の全文を示す確認ダイアログ。「ブラウザで開く」で既定のブラウザが開く。表示文字と行き先のドメインが違う場合は注意の帯が出る。
4. 応答に `<script>alert(1)</script>` や `[x](javascript:alert(1))` を含めさせても、実行されず文字として出る／リンクにならない。リモート画像は読み込まれず「[画像: …]」と出る。
5. 応答の逐次表示中に崩れない。非常に長い応答（数千行）は整形せず文字表示になり「整形して表示」ボタンが出る。

## 12. 会話内検索（Ctrl+F）

1. 会話画面で Ctrl+F → 右上に検索帯。語を入力すると件数「2 / 5」とハイライト（青系）。Enter／Shift+Enter／F3 で移動、Escで閉じて入力欄へフォーカスが戻る。
2. 太字やコードをまたぐ語、日本語の語もヒットする。応答が流れてくる間も検索結果が追従する。
3. 検索は表示済みの範囲だけで、検索のために履歴の取得や再開は起きない（部分取得の会話では「読み込み済みの範囲を検索」と出る）。

## 13. 編集して再送・再生成（要注意。実際のCodexで）

1. 自分の発言にマウスを乗せ「編集して分岐…」、最後の応答に「もう一度…」。実行中のチャットでは押しても「実行中は使えません」の理由が出るだけ。
2. 編集して分岐: 内容を直して「分岐して送信」→ 元の会話は残り、新しいチャット（名前に「（編集）」、ヘッダーに「編集から」）が開いて送られる。添付は引き継がれない旨が出ている。
3. **最重要（H1）**: 元のチャットの権限を「読み取り専用」に（または承認必須に）してから「もう一度…」→ 分岐先でも**同じ権限**で動き、ファイルを書けない／承認を求める。モデルも元と同じ。
4. 応答待ちの間（ダイアログに「実行中」）は閉じられない。終われば閉じられる。同じ操作を2回押しても分岐は1つだけ。
5. 「分岐して入力欄へ（送らない）」では、送信されず依頼が入力欄に入る。
6. 最初の発言の編集は、新しいチャットの入力欄に入るだけで送られない。
7. App Serverのログ（可能なら）に `thread/resume` が出ていないこと。

## 14. 状態不明の子の「履歴で再確認」

1. 親が完了して子の一部が「状態不明」のチャットを開く。ドックの「状態不明の子 n件」の隣の「履歴で再確認」を押す。
2. 終端が履歴で確認できた子は「履歴で完了を確認」の表示になる。確認できない子は状態不明のまま、通知は「n件確認／状態不明のまま」を正直に出す。resumeは起きない。

## 15. 設定: 表示（文字サイズ・テーマ）

1. 設定 → 表示。テーマ「ライト／ダーク／OSに従う」を切り替え、画面全体とタイトルバーが追従する。再起動後も残る。
2. 画面の文字（小・標準・大）と本文の文字（4段）を変えると、左一覧の行の高さ・会話の文字が変わる。ウィンドウを閉じて開き直しても残る。

## 16. 容量・その他

1. 設定 → 保存と容量: 「画面表示のキャッシュ（WebView2）」が別行で出る（メタデータに混ざらない）。削除ボタンは無い。
2. 変更を戻す・差分で「控えがない」理由が1つ表示される。Gitリポジトリでない作業フォルダでは、メニューの差分・戻すに「Gitリポジトリではありません」の理由が出る。
3. 設定以外のダイアログ（削除確認・終了確認など）もEscで閉じる。日本語入力の変換中のEscでは閉じない。

読みにくい・崩れている場所（画面名・幅・テーマ・文字サイズ）、動作が前と違う操作、元の権限と違う分岐先の動作（最重要）。
