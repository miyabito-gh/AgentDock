# 実機確認手順 — 段階④-UI（見た目の改善）

対象: NSIS版（`app/src-tauri/target/release/bundle/nsis/AgentDock_0.0.1_x64-setup.exe`）。設計は `app/DESIGN_UI.md` v0.2。
見た目だけの変更なので、**動作が前と同じか**と**見た目が読みやすいか**を見る。消した・移した文言の一覧は DESIGN_UI.md §7。

## 0. 準備

```powershell
# 起動中のAgentDockを終了してからインストール（トレイにも残さない）
Get-Process AgentDock -ErrorAction SilentlyContinue | Stop-Process
& "C:\Users\wmasa\Documents\Rust\AgentDock_claude\app\src-tauri\target\release\bundle\nsis\AgentDock_0.0.1_x64-setup.exe"
```

インストーラーの指示に従って上書きインストールし、AgentDockを起動する。

## 1. 会話の見える量（今回の主目的）

1. 既存の会話（できれば再起動後の履歴のみのチャット）を開く。ウィンドウは最大化（1080pxの高さ）。
2. 見る: ヘッダーが**1行**（題名・状態・鮮度・作業フォルダ・「…」）で、入力欄が**2行＋操作1行**に収まり、会話が縦に広い。以前あった「保存履歴から表示しています」の黄色い帯が出ない。
3. 鮮度の「履歴のみ」をクリック → 吹き出しに旧帯と同じ説明が出る（Escで閉じる）。
4. アプリ内の疑似タイトルバー（最小化・最大化ボタンの行）が無く、Windows標準のタイトルバーだけ。右端付近のメニューバーに「Codex 0.160.0」が出る。クリックして接続先メニューが開く。×を押すとトレイに格納される。

## 2. ヘッダーの「…」メニュー

1. ヘッダー右端の「…」をクリック。差分・変更を戻す・レビュー・分岐・Goal・作業フォルダ変更・状態を再照合・すべての操作（Ctrl+K）が並ぶ。
2. 見る: 未確認の操作は名前の直後に灰色の枠で「未確認」。使えない操作は理由がツールチップに出る。
3. 差分を開く → 閉じる。変更を戻すを開き、フッターの右下に「戻す」系ボタン、左下に副操作、右端に「閉じる」。**実際に戻す操作はしなくてよい**（開いて内容を見るだけ）。
4. 実行中のチャットで、入力欄の「中断」が押せる（ヘッダーの中断は無くなった）。

## 3. 入力欄

1. 入力欄の右下付近の「⋯」をクリック → 速度・計画／実行・受理の全文が出る。
2. モデルや推論の選択を変えて送る前後で、1行目に「未受理」「受理未確認」が出るか（変更後すぐ）。受理後は消える。
3. 長文を貼ると入力欄が最大160pxまで伸び、送信後に元の高さへ戻る。日本語入力（IME変換中）で文字が飛ばない。

## 4. 左一覧とドック

1. 左一覧: 上部が2行（新規＋更新／検索）。行が詰まっている。検索に文字を入れると「アーカイブも含める」が出る。
2. ドック（親子エージェントがいるチャット）: 上部1行。「表示 ▾」から「親のみ」「終了済みも表示」を切替。「?」で説明。子カードに役割・担当・パス・活動・時刻が収まり、**横スクロールが出ない**。失敗した子の「確認済みに」で隠せる。
3. 状態の色: 実行中＝青、要対応＝黄、失敗＝赤、完了＝緑✓、状態不明＝破線。**黄色は承認・質問などの要対応だけ**に使われている。

## 5. ペイン幅の変更（新機能）

1. 左一覧とチャット本文の境目にマウスを置く → 左右矢印のカーソル。ドラッグで幅が変わる（180〜400px）。ドックの境目も同様（260〜520px）。
2. 境目をクリックしてフォーカスし、←→（8px）、Shift+←→（32px）、Home／End（最小／最大）、Enter（既定幅）。ダブルクリックでも既定幅に戻る。ドラッグ中にEscで元に戻る。
3. 幅を変えてアプリを**完全終了→再起動**（トレイの「終了」）。幅が復元される。
4. ウィンドウを狭める: 1279px以下でドックが一時パネルに、959px以下で左一覧も一時パネルになり、ハンドルは出ない。広げると保存した幅に戻る。

## 6. ダーク・ライト

```powershell
# 現在のテーマ確認（0=ダーク、1=ライト）
Get-ItemPropertyValue "HKCU:\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize" -Name AppsUseLightTheme
```

Windowsの「設定 → 個人用設定 → 色 → モードを選ぶ」でダーク／ライトを切り替え、AgentDockが追従するか（再起動不要が理想。必要なら再起動）。見る: 主画面、ドック、設定→容量、変更を戻す、差分で、読めない色・白飛び・コントラスト不足がないか。

## 7. 設定・容量

設定（左の縦タブ）→ 容量: 合計＋内訳バー＋凡例、このチャット、変更の控え、チャット別の表。**数値と単位（例 135 KB）が途中で改行されない**。右端の列が切れない。再集計ボタンが動く。

## 8. 通知・フォーカス・監視窓

1. 子エージェントが完了/失敗する、または承認待ちになったとき、OS通知が出る。**通知でフォーカスが勝手に動かない**（入力中の文字が影響を受けない）。
2. コンパクト監視窓（開ける場合）で、カードが横スクロールなしで読める。
