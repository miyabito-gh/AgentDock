## 1. 入力欄の下段（35・36）

1. チャットを開き、入力欄の下段を見る。**1段**に収まっていること（添付・モデル・強度・「…」と、右端に送信）。
2. 幅を 1000px → 960px → 720px に縮める／ドックを表示・非表示にする。実行中のチャットでも **2段にならない**こと。狭いと強度が「…」へ移る。
3. モデル・強度の選択部品に**枠がなく**文字だけ。hoverで▾が濃くなる。Tabで移動したとき枠（focus）が見える。ダークでも読める。
4. 「…」メニューに権限・計画／実行がある。権限を既定以外（読み取りのみ／フルアクセス）に変えると下段に小さな「権限: …」の印が出る。既定に戻すと消える。計画にすると「計画」の印。

## 2. 追加指示（37）

1. 実行中のチャットで、入力して送信ボタン横の **▾** を開く。「完了後に送信（既定）」「追加指示で送る」。切替の見出し（seg）は出ない。
2. 「追加指示で送る」または **Ctrl+Shift+Enter** で、実行中のturnへ追加指示が入る。次の送信は既定（完了後）に戻っている。
3. 実行中に通常送信（完了後に送信）してキューに入れる→その項目の短いボタン **「追加指示」** を押す→実行中のturnへ送られ、元の項目が消える。
4. 実行中でないときやモデル変更中は、項目が無効で理由がツールチップに出る。
5. （起きたら）受理不明のときは項目が残り「履歴と照合」が出る。自動送信されない。

## 3. 作業フォルダを開く（41）

ヘッダーの作業フォルダ表示の横の小さなフォルダアイコンを押す→エクスプローラーで開く。ネットワーク（UNC）や存在しないパスでは無効で、理由がツールチップに出る。ヘッダーの高さが増えていない。

## 4. 見出しメニュー（34）

左一覧を「プロジェクトごと」にし、見出しの「…」を開く。「このプロジェクトで新しいチャット」と短く、先頭フォルダは2行目の薄い補足で、長くても枠から出ない。フォルダ見出しも同様。

## 5. 途中経過の折りたたみ（38）

1. 複数の途中発言があった完了済みturnで、「作業の経過（N件・所要時間）›」が出て、依頼と最終回答だけが見える。押すと途中発言と作業の記録が展開する。
2. **実行中のturnは畳まれず**流れる。完了すると畳まれる（自分で開いていれば畳まれない）。
3. 失敗・中断したturn、最終回答がないturnは畳まれない。承認・質問・エラーは畳まれない。
4. Ctrl+Fで畳み内の発言の語を検索→自動で展開される。チャットを切り替えて戻っても開閉が保たれる。
